# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。

## 曝光预算闭环（`/exposure`）
- 展品、展线位置、照度读数、布展方案接成曝光预算：位置绑定照度计，方案绑定展品与位置，预算按展品设限值（lux·h）。
- 读数按「设备 + 时段」去重合并，同时段以晚到读数为准；晚到读数更新原时段后全量重算累计曝光。
- 累计超限的展品立即退回库房周转区，原布展签字失效；周转区容量满时排队，未轮到的展品留在展线上继续累计，腾出位置后按队列自动撤下。
- 读数导入失败（离线或校验不通过）时保留批次，可重试或作废；重试成功后合并并重算。
- 历史数据无曝光记录的展品按当前读数回填台账起点（估算值单独标记），原展线位置和布展签字保持不变。
- 领域逻辑集中在 `src/services/exposure.ts`（纯函数），状态与持久化在 `src/stores/exposure.ts`。
